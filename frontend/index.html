Taxpayer Quick Facts — Union Budget 2025-26

The BE → RE → Actuals Problem

India's budget has a three-stage churn: BE (announced Feb 1) → RE (next year's budget) → Actuals (audited, 1-2 years later). Always ask: was the money actually spent, or just allocated? Example: Jal Jeevan Mission was allocated ₹70,163 crore (BE 2024-25), revised to ₹22,694 crore (RE) — and even then spent only ₹22,612 crore. See the Expenditure section for full actuals.

Reading State Budgets — Three Caveats

1. Conventions differ: some states quote total expenditure including debt repayment (e.g., Rajasthan's ₹5.37 lakh crore); others quote net disbursement (e.g., Tamil Nadu's ₹4.39 lakh crore) — figures are not perfectly comparable across states. 2. Election timing: Tamil Nadu, Kerala, West Bengal, Assam and Bihar's 2025-26 budgets came from pre-election governments; their FY2026-27 budgets will reflect the new 2026 governments. 3. Deficits: 14 states budgeted deficits above 3% of GSDP — the highest are Arunachal Pradesh (8.9%), Sikkim (5.8%), Tripura (4.9%), MP (4.66%) and Mizoram (4.57%); the most conservative are Gujarat and Jharkhand (2.0%), Goa (2.1%) and Haryana (2.67%).

Key Finding

Only data.gov.in and API Setu offer official, documented APIs at scale. Almost everything else — budget documents, CAG reports, Parliament proceedings, PIB releases — is PDF/HTML/Excel requiring scraping and parsing. A live platform must invest heavily in robust data extraction pipelines.

Architecture & Deployment

One Python process serves the frontend, the JSON API and the scheduled data pipelines — deployable with Docker or any Procfile platform in minutes. The PIB feed refreshes itself in-process; no external cron is required.

02

Deploy It

Docker

Any host with Docker

Two-stage image, runs as non-root (uid 10001), installs requirements.txt and starts uvicorn on $PORT.

docker build -t jandrishti .
docker run -p 8000:8000 \
  -e ALLOWED_ORIGINS="https://yourdomain.in" \
  jandrishti
Render / Railway

Procfile platforms (free tier works)

Push this repo to GitHub, create a Web Service, and the included Procfile does the rest. The scheduler runs inside the web instance — one service, no workers, no add-ons.

# Procfile (already in the repo)
web: cd backend && uvicorn main:app \
  --host 0.0.0.0 --port $PORT
VPS / own server

Ubuntu or any Linux box

Python 3.12+, then run behind Nginx or Caddy for automatic HTTPS. ₹400–800/month on a small cloud instance.

pip install -r requirements.txt
cd backend
uvicorn main:app --host 0.0.0.0 --port 8000

Top Pipeline Risks

Risk

PDF is the dominant format

Budget documents, CAG reports, and Parliament Q&A are all PDF. Invest early in robust table extraction (Camelot/pdfplumber) + OCR fallback for scanned documents.

Risk

No SLAs or notification mechanisms

No government data source offers webhooks or change notifications. The pipeline must poll-and-diff with content hashes, and cache everything aggressively.

Risk

Schema drift across years and states

Plan/Non-Plan was replaced by CSS/CS/OCE post-2017. Ministry names change. Demand numbers get renumbered. Maintain a canonical ministry/department registry with effective dates.

Risk

Undocumented internal APIs can break

sansad.in and data.gov.in search endpoints are undocumented and can change without notice. Pin versions where possible and monitor for breakage.

Risk

data.gov.in maintenance windows

The portal has gone down for multi-week maintenance. Mirror everything you depend on locally.

Risk

Citation discipline is essential

Always store source URL + document title + access date on every record. Government documents get silently revised — your data must remain auditable.
